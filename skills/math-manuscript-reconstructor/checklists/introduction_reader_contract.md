# Introduction Reader Contract Checklist

## Core understanding

- [ ] The exact problem is visible without consulting the proof body.
- [ ] The benchmark or motivating theorem is stated concretely.
- [ ] The strongest relevant prior result and the exact remaining gap are distinguished.
- [ ] The main theorem appears as soon as it is accurately readable.
- [ ] The theorem is stated at exactly the strength proved.
- [ ] A concrete obstruction explains why the result is not routine.
- [ ] The central idea is described through the control or capability it unlocks.
- [ ] The theorem's meaning and limits are explicit.

## Composition

- [ ] No substantial paragraph survives the swap test.
- [ ] Every pre-theorem paragraph is indispensable for understanding the statement or its significance.
- [ ] Literature is organized by mathematical claim, not author chronology.
- [ ] For reconstructed Introductions, outside scholarship was searched by multiple routes when accessible and pivotal results were verified in primary sources.
- [ ] Authors receive explicit credit for originating problems, direct prior theorems, relevant parallel advances and borrowed methods.
- [ ] A credible parent mathematical program was tested and a substantive program-level opening was chosen when earned.
- [ ] Exact novelty boundaries, unresolved sources and unavailable searches are stated honestly.
- [ ] Paragraphs create information changes rather than fill fixed roles.
- [ ] The proof overview opens the bottleneck and compresses bookkeeping.
- [ ] The ending does not ceremonially repeat the Abstract.

## Conditional PDE extension

- [ ] When Protocol 04t is active, every theorem coordinate on which novelty depends is recoverable.
- [ ] The PDE result delta is explicit on concrete axes, and incomparable frontiers remain incomparable.
- [ ] The solution class, topology, and emphasized assumptions are not silently strengthened.
- [ ] The proof overview links the decisive PDE mechanism to the closure interface.
- [ ] Theorem boundaries, method boundaries, known obstructions, and open regimes are not conflated.
- [ ] Only the applicable checks from `pde_introduction_reader_contract.md` are imposed.

## Optional depth

- [ ] Parent-program context is used only when it changes theorem interpretation.
- [ ] Scientific context is used only when the model or regime is operative.
- [ ] Editorial amplification is used only to repair verified under-positioning.
- [ ] No optional module is present merely because the paper is long or intended for a strong journal.
