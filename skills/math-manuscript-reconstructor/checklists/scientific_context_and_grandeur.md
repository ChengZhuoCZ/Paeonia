# Scientific Context and Grandeur Checklist

- [ ] Mathematical ambition and scientific-context depth were selected independently.
- [ ] A specialist audience did not automatically suppress scientifically operative context.
- [ ] Every substantial scientific claim has an evidence anchor.
- [ ] Model variables/parameters/regimes are mapped to the mathematical objects actually used.
- [ ] Background covers origin, mechanism, regime/scaling, and math bridge when substantial context requires them.
- [ ] No paragraph survives solely because it sounds physically motivating.
- [ ] The Introduction returns from scientific context to the exact theorem.
- [ ] The theorem's scientific interpretation is weaker than or equal to its evidence ceiling.
- [ ] GRAND/GRAND_PLUS openings are not routine-definition-first when a larger verified stake exists.
- [ ] The first two pages expose the big problem, frontier, obstruction, theorem scale, and mechanism.
