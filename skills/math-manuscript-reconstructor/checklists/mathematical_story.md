# Mathematical Story Checklist

For EXPANSIVE/GRAND/GRAND_PLUS Introductions:

- [ ] Can I name a mathematically specific parent program above the focal conjecture?
- [ ] Can I identify the canonical principle/theorem that makes the focal problem natural?
- [ ] Is there a genuine scale/category transition (limit→finite, local→global, continuum→discrete, etc.)?
- [ ] Have I explained why that transition is not routine?
- [ ] Is the central tension connected to an actual proof obstruction?
- [ ] Does the literature map mathematical ancestry rather than chronology?
- [ ] Are parallel problems included only when they reveal structure?
- [ ] Does the main theorem get interpreted back at parent-program scale?
- [ ] Does the proof overview explain the mechanism that crosses the story transition?
- [ ] Can a reader state the larger mathematical problem after reading the Introduction?
- [ ] Have I removed generic grandeur such as “fundamental problem in mathematics” when no precise relation follows?
- [ ] If scientific context is present, is the mathematical program still visible?
