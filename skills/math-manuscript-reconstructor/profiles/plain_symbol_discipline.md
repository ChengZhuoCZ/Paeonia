# Plain Symbol Discipline

Default notation policy:

- Keep a manuscript-wide table of recurring canonical symbols.
- A recurring visible symbol may denote only one recurring mathematical object in that table.
- No symbol, including `\Delta`, has a preferred meaning by policy.
- Local dummy variables are excluded from the duplicate-symbol audit.
- When a recurring-symbol duplicate is found, rename one object consistently.
- Prefer ordinary Roman/Greek letters and semantic subscripts.
- Avoid `\mathscr` and `\mathfrak`; use `\mathcal` sparingly for genuine named sets/classes/spaces or established field notation.
- Do not distinguish unrelated objects only by changing font.

- When several collision-free choices are equally standard, use `profiles/changfeng_gui_notation_prior.md` as the default soft notation prior.
