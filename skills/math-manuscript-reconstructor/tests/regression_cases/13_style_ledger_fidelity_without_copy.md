# Regression 13 — Fidelity Without Imitation

Input: a style corpus with recognizable exposition habits.

Expected:
- final manuscript has low ordinary-prose overlap with the corpus;
- final manuscript still satisfies supported abstract traits such as obstacle-driven tool changes and local justifications;
- transition frequencies and sentence templates are not copied mechanically;
- audit can return `REVIEW_STYLE_LEDGER_DRIFT` even when source-overlap is low, because non-copying alone is not sufficient.
