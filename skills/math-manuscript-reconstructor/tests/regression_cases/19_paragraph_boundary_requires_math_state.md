# Regression 19 — Paragraph boundary requires mathematical state

## Failure
A proof is split every three sentences solely to create visual variation.

## Required behavior
Merge breaks that do not correspond to a new obligation, method, regime, legality check, auxiliary return, substantial display consequence, equality audit, conceptual pause, or closure.

## Gate
`PARAGRAPH-FINGERPRINT-FIDELITY` fails if paragraphing is cosmetic.
