# Protocol 13 — Multi-Source Reconciliation

Multiple manuscripts are merged only at the semantic layer.

## Reconciliation table

For each semantic claim record:
- source variants;
- statement differences;
- normalization differences;
- proof-route differences;
- status of each route;
- selected canonical formulation;
- reason for selection.

## Selection criteria

In order:
1. correctness;
2. exact scope needed for main theorem;
3. proof closure;
4. conceptual economy;
5. exposition quality;
6. compactness.

Never choose a route merely because it appears in the most polished source.
