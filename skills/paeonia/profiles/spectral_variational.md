# Profile — Spectral / Variational Mathematics

Prioritize:
- admissible class and constraints;
- normalization under scaling;
- existence/compactness;
- first and second variation;
- coercivity and null directions;
- spectral multiplicity;
- shape derivative assumptions;
- equality and rigidity;
- global versus local minimality.


## Plain symbol discipline

Apply `profiles/plain_symbol_discipline.md`. In particular, check recurring canonical symbols for duplicates and avoid decorative script/fraktur notation.
