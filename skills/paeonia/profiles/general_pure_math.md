# Profile — General Pure Mathematics

- Prefer theorem-driven exposition.
- Keep preliminaries minimal and local.
- Use remarks for genuinely useful perspective, not proof leftovers.
- Prefer semantic lemma names in prose when they aid recall.
- Avoid overexplaining standard algebra while never skipping nonstandard reasoning.


## Plain symbol discipline

Apply `profiles/plain_symbol_discipline.md`. In particular, check recurring canonical symbols for duplicates and avoid decorative script/fraktur notation.
