# Scientific/Physical Context Profile for Research Introductions

This profile governs how external scientific context enters a mathematical paper.

## Default posture

Scientific background is neither mandatory decoration nor something to suppress for expert readers. Its depth is chosen from the mathematics-to-model relation.

### Strong signals for substantial context

- the equation is a named physical/biological model;
- the theorem isolates a physically distinguished regime or scaling;
- a variational energy has a direct scientific interpretation;
- the boundary condition or geometry represents a concrete physical constraint;
- the problem originated in mathematical physics and that history explains the conjecture;
- the theorem has a clean translation into an observable or stability statement;
- the proof exploits structure inherited from the model.

### Weak signals

- a generic PDE happens to appear in physics somewhere;
- one can invent an engineering analogy;
- a scientific application is remote from the theorem;
- the context does not change how the reader understands the mathematical problem.

## Prose principles

- scientific nouns should precede generic meta-language;
- explain mechanisms before listing applications;
- introduce parameters with their scientific role when that role matters;
- move from physical/model language to mathematical structure explicitly;
- return from every scientific excursion to the theorem;
- allow longer contextual paragraphs when several modeling facts are causally linked;
- do not write a popular-science preface for a specialist paper.

## Mathematical-physics cadence

A useful cadence, when earned, is:

`phenomenon → idealization → canonical equation/energy → mathematical obstruction → theorem`.

For classical spectral geometry, another is:

`physical eigenfrequency problem → isoperimetric principle → constrained geometric class → discrete/continuous tension → theorem`.

These are abstract cadences, not sentence templates.
