# Profile — Geometric Analysis

Prioritize:
- geometric normalization;
- invariance groups;
- coordinate-free statement before coordinate proof when useful;
- conformal/scaling covariance;
- compactness and bubbling alternatives;
- equality/rigidity classification;
- precise quotienting by symmetries.


## Plain symbol discipline

Apply `profiles/plain_symbol_discipline.md`. In particular, check recurring canonical symbols for duplicates and avoid decorative script/fraktur notation.
