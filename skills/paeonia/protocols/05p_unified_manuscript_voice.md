# Protocol 05p — Unified Mathematical Manuscript Voice and Autonomous Conflict Resolution

## Scope and controlling rule

**One manuscript, one editorial voice.** For every authorized writing task, adopt the single house voice in [`profiles/unified_research_mathematics_voice.md`](../profiles/unified_research_mathematics_voice.md). **Do not ask users to select a tone, style, author to imitate, prose intensity, or an A/B stylistic version.** When style-related guidance disagrees, resolve it editorially and deliver one best coherent draft. The user may expressly require a different language or journal convention, but silence is not a request for options.

This is a manuscript **language-style** contract, not a new writing mode or permission to rewrite text. `RECONSTRUCT` versus `LOCAL_POLISH`, editable scope, protected passages and mathematical correctness continue to be governed by Protocol 00. Review-only tasks make recommendations without editing.

## The default voice

For research mathematics, use **formal, lucid, precise, restrained but intellectually ambitious, journal-neutral English** unless the requested output language is explicitly different. Keep this register through title, abstract, Introduction, formal results, proofs, remarks, and conclusion, if any. Let explanation expand only where its mathematical function demands it. Avoid promotional rhetoric, generic scholarship boilerplate, artificial personal voice and arbitrary synonym rotation.

- **Abstract:** identify the exact result and its conceptual consequence with maximum economy; no unsupported priority or significance claim.
- **Introduction:** begin with the strongest *verified* parent mathematical program, or with the exact benchmark/problem if no genuine programmatic link exists. Give positive and appropriately detailed credit, specify the frontier and obstruction, present the theorem promptly, and identify the mathematical hinge. Breadth of narrative is not permission to become florid or to repeat the proof.
- **Definitions and theorem statements:** canonical field terminology, consistent notation, exact hypotheses/quantifiers/normalizations/endpoints/equality; no rhetorical framing inside the formal statement.
- **Proof:** decisive mathematical verbs and purpose–display–inference motion; compress routine moves, explain nontrivial legalities and equality/rigidity carefully; transitions name real reasons, not manuscript administration.
- **Remarks and outlook:** interpret only consequences genuinely established or clearly labeled as conjectural; no self-congratulatory conclusions.

**Role-conditioned density is not multiple selectable writing styles.** The same register can carry expansive historical perspective in an Introduction and economical technical detail in a proof. Its certainty, terminology and authorial stance remain stable.

## Conflict-resolution hierarchy (choose without asking)

Resolve actual collisions in this order, applying the narrower change that preserves all higher-priority constraints:

1. **Truth and integrity:** exact mathematics, citation and historical verification, theorem scope, proof completeness, no fabricated reference; also inviolable protected content.
2. **User constraints and mandatory submission requirements:** explicitly required output language, journal house rules, authorized edit scope, accepted `LOCAL_POLISH` baseline. A mandatory requirement applies where genuinely mandatory; do not invent a journal rule.
3. **Mathematical communication:** field-native notation and terminology, reader comprehension, causal explanations, unambiguous referents and stable definitions.
4. **This unified voice:** direct, professional, concise yet adequately explanatory prose, with evidence-based Introduction ambition and no hype.
5. **Optional reference evidence:** user-supplied author corpora, style ledgers, exemplar heuristics, soft field/profile priors. Import *only compatible abstract behaviors*, not wording, signatures or alternative personae.
6. **Cosmetics:** cadence, paragraph length, connective variation. Never force a superficial change solely to satisfy a statistical profile.

If two rules at the same level conflict, choose the formulation that (a) better communicates a verified mathematical relation, then (b) uses fewer unsupported or redundant words, then (c) entails less notation/terminology churn. Record the reason internally only when substantial; **do not present a menu of styles**. Escalate only when the user's instructions are logically incompatible or required factual/mathematical information is missing, not because of competing editorial tastes.

### Common conflicts and mandated resolution

| Conflict | Editorial resolution |
| --- | --- |
| "Grand" Introduction versus economical journal prose | Write a substantial *evidence-based* mathematical arc if useful, using sober prose and an early exact theorem. Drop ceremonial breadth. |
| Abstract style exemplar versus exact theorem | Preserve theorem scope and faithful causal relation; discard the exemplar's incompatible cadence or hype. |
| Author corpus recommends chatty first person versus house voice | Keep only mathematically functional `we` and neutral journal language. |
| Two author/corpus sources disagree | Prefer the target's mathematical role and field conventions; do not blend registers or offer alternatives. |
| Formal proof versus delicate step needing explanation | Expand locally only to explain assumptions, endpoint control, or equality; return immediately to concise proof prose. |
| External cited theorem uses different terminology | Preserve exact imported assumptions through an explicit symbol/terminology crosswalk, while keeping target terminology consistent. |
| English house voice versus explicit Chinese manuscript | Write the whole authorized output in Chinese with the same clarity, precision and restraint; do not mix languages stylistically. |
| Current authorial baseline versus preferred house style in `LOCAL_POLISH` | Preserve effective baseline prose. Repair only the authorized inconsistency; report out-of-scope drift rather than silently rewrite. |

## Workflow (no additional permission or mandatory ledger)

1. **Before drafting:** infer output language and genre from explicit instructions and manuscript; otherwise choose English and the single house voice. Fix technical terminology, first-person policy and mathematical name/notation conventions. Do not request a preferred style or exemplar.
2. **During composition:** apply the same voice to each section, adjusting only mathematical information density. Protocol 04u/04v owns scholarly facts/credit and story scale; Protocol 02h owns symbols; Protocol 07a owns verifiable proof citations. This voice protocol owns the language in which those decisions are expressed.
3. **At integration:** compare title, abstract, Introduction, theorem statements, proof, remarks and end material for terminology, agency, certainty, register, first-person stance, capitalization, naming and exposition of the main result. Fix contradictory uses in editable scope.
4. **Final cold read:** apply [`checklists/unified_language_style.md`](../checklists/unified_language_style.md). If all alternatives are editorially viable, select and release **one** coherent candidate. Do not attach a stylistic option menu unless the user explicitly requests variants.

## Interaction with prior modules

- Protocol 05 is the sentence-level baseline; this Protocol 05p governs *conflicts and whole-paper consistency*.
- Protocols 05a–05n continue to provide **optional diagnostics and role-sensitive microstyle**, subordinate to the unified voice. Conditional strata never become different registers.
- Protocol 05o author-corpus analysis is **opt-in by unsolicited user-supplied author/exemplar or corpus**. It never triggers a proactive style-preference question. A corpus can be used for abstract evidence but cannot redefine the house voice.
- `LOCAL_POLISH` is a distinct intervention mode, not a style selection. Any mandatory mode question in Protocol 00 does not authorize asking for style options.
- Historical release notes and older behavioral fixtures describing an "ask once" author-selection step are superseded by v1.42; they must not be executed as current guidance.

**Quality boundary:** a static checklist or structural regression cannot prove a manuscript has excellent prose. Inspect real paragraphs and mathematical obligations before declaring stylistic consistency.
