# Regression 16 — Authorial density asymmetry

## Input

A proof contains both a routine algebraic substitution and a delicate endpoint limit requiring uniform estimates.

## Required behavior

Classify the algebra as `ROUTINE` and compress it. Classify the endpoint passage as `DELICATE` and preserve the uniformity argument locally.

## Gate

`AUTHORIAL-DECISION` fails if both passages receive the same explanatory density merely for stylistic symmetry.
