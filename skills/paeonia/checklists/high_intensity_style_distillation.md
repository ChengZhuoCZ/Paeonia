# High-Intensity Style Distillation Checklist

- [ ] Corpus is large enough for multiple mathematical strata.
- [ ] Style is conditioned on mathematical role rather than a global average.
- [ ] Routine, delicate, technical, bridge, theorem-leadin, and opening contexts are distinguished where supported.
- [ ] Holdout / cross-section stability has been checked for default traits.
- [ ] Strong, moderate, and tentative evidence are separated.
- [ ] Corpus statistics are evidence only, never generation targets.
- [ ] No source sentence, source paragraph, phrase inventory, or source role sequence is stored.
- [ ] Research-genre projection is explicit.
- [ ] Textbook/monograph corpus is not used to infer research-priority claims.
- [ ] Introduction macro narrative and microstyle reference roles are separated.
- [ ] Final prose uses context-conditioned realization rather than vocabulary imitation.
