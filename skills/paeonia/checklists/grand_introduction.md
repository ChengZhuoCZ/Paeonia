# Research Introduction Reconstruction Checklist

## Narrative truth

- [ ] Introduction scale is justified by the actual theorem and verified literature.
- [ ] The opening begins at the largest useful mathematical scale, not with generic prestige prose.
- [ ] The current frontier and unresolved gap are stated accurately.
- [ ] A natural prior route and its precise obstruction are identified when relevant.
- [ ] The main theorem is exposed as soon as it is readable.
- [ ] The result hierarchy reflects reader significance, not proof chronology.
- [ ] Every literature item has a narrative role.
- [ ] Every adjacent problem has a shared-structure / decisive-difference bridge and a return to the main thread.
- [ ] The proof overview is a mechanism chain, not a section itinerary.
- [ ] Priority / sharpness / completeness / open-problem claims are verified or removed.

## From-scratch reconstruction

- [ ] Any supplied Introduction was used only for mathematical claims, citation candidates, terminology, and facts to verify.
- [ ] Source Introduction sentences were not polished line-by-line.
- [ ] Source paragraph order, theorem latency, citation order, and rhetorical escalation were not inherited.
- [ ] `IntroductionParagraphPlan` was built before final prose.

## Paragraph architecture

- [ ] Each paragraph has one dominant mathematical function.
- [ ] Consecutive same-role fragments are merged unless a real mathematical state change separates them.
- [ ] Each noninitial paragraph enters through a mathematical referent, not only an administrative transition.
- [ ] Each nonfinal paragraph leaves a mathematical reason for the next paragraph.
- [ ] Literature is clustered by claim, not author chronology.
- [ ] A paragraph-removal test has been applied to background and adjacent-problem material.
- [ ] The research audience is not given textbook preliminaries unless needed.

## Theorem cadence

- [ ] Orientation, formal theorem, and interpretation are functionally distinct.
- [ ] Formal theorems are not stacked without mathematical escalation.
- [ ] Post-theorem prose does not paraphrase the displayed statement.
- [ ] The strongest result is not buried under secondary refinements.

## Prose realization

- [ ] Paragraph openings are mathematically led where natural.
- [ ] Repeated `In this paper / We now / More recently / It is worth noting / This result` patterns have been reviewed.
- [ ] Literature sentences are result-centered rather than author-centered.
- [ ] Generic importance adjectives have not replaced mathematical content.
- [ ] The first and last sentences of paragraphs form a coherent compressed spine.
- [ ] The proof mechanism is written causally rather than as a checklist.
- [ ] The organization paragraph is present only if it adds real navigation.
- [ ] The Introduction does not end with a ceremonial repetition of the Abstract.

## Integrity

- [ ] Every Introduction claim maps to closed mathematics or verified scholarship.
- [ ] Reference-Introduction wording and paragraph choreography remain independent.
- [ ] `GRAND-NARRATIVE-INTEGRITY` passes.
- [ ] `INTRODUCTION-PROSE-INTEGRITY` passes.

## Editorial positioning

- [ ] `NarrativeAmbitionLedger` selects the strongest defensible scale.
- [ ] Verified central strong claims are surfaced directly rather than euphemized.
- [ ] Historical exposition reaches the exact pre-paper frontier.
- [ ] The theorem interpretation explains what mathematical picture changes.
- [ ] Methodological afterlife is stated at its verified level.
- [ ] Amplification uses only context, contrast, obstruction, consequence, or method significance.
- [ ] Every amplification respects its factuality ceiling.
- [ ] A specialist editor can recover the big problem, exact gap, exact advance, and theorem strength from the first part of the Introduction.
- [ ] `EDITORIAL-IMPACT` passes.
